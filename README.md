Motion (бывший Framer Motion) — самая популярная для React/Vue проектов. Декларативный API, привязка к state, GPU-ускорение до 120fps.

GSAP — отраслевой стандарт для сложных, кастомных анимаций: таймлайны, скролл-триггеры, SVG, WebGL. Не привязан к фреймворку, подходит для любого сайта.

Lottie — лидер по общей доле рынка. Не библиотека анимации в чистом виде, а плеер: дизайнер рисует в After Effects → экспорт в JSON → вставляется на сайт. Используется для иконок, иллюстраций, сложных лендингов.

Нативный CSS Scroll-Driven Animations — новинка, в 2026 уже поддерживается всеми браузерами. Позволяет делать анимации, привязанные к прогрессу скролла, без единой строчки JS — это меняет расклад, раньше для этого нужен был GSAP ScrollTrigger.

По стилям сейчас в тренде: параллакс-эффекты, кинетическая типографика (текст двигается по мере скролла), абстрактная геометрическая анимация в фонах/лоадерах, микро-интеракции на hover/клик, и 3D/WebGL для более "премиальных" сайтов. При этом акцент сместился на производительность — тяжёлые эффекты урезают в пользу CSS/GPU-ускоренных решений.

Если сайт для детской тематики (как обсуждали) — подойдут мягкие микро-интеракции и лёгкая кинетическая типографика, без агрессивного параллакса или 3D — они больше подходят для лендингов, где нужен "вау"-эффект.
