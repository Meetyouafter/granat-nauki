# Гранат науки

Сайт детского психолога: консультации, подготовка к школе, тьюторство.
Публичная часть на двух языках (ru — оригинал, en — машинный перевод через DeepL)
и админка, в которой владелец сайта сам правит контент без правки кода.

## Архитектура

```
             ┌──────────────────────────────────────────────┐
 посетитель ─▶  frontend/  — Next.js                         │
             │   • публичные страницы (RSC, SSG/ISR)         │
             │   • API: app/api/**  (route handlers)         │──▶ PostgreSQL
 админ ──┐   │   • server actions (формы сайта)              │──▶ DeepL
         │   │   • авторизация админки                       │
         │   └──────────────────────────────────────────────┘
         │                      ▲
         └─▶ admin/  — Vite SPA ┘  ходит в /api/admin/** с сессией
                                ▲
     bot/ (Go, позже) ──────────┘  ходит во внутренний API, в БД не лезет
```

**Next.js отвечает за всё серверное**: чтение и запись в БД, валидацию, авторизацию,
перевод, сброс кэша. Отдельного бэкенда нет.

- Публичные страницы читают БД **напрямую в серверных компонентах**. Своему же API
  они не шлют HTTP-запросы.
- Для админки и бота есть **route handlers** под `app/api/admin/**`. Все они закрыты
  авторизацией.
- **Формы сайта** (связь, запись на консультацию) сделаны на server actions.
- **После правки в админке** API вызывает `revalidateTag`, и публичная страница
  пересобирается без ожидания и без cron.
- **Перевод делается при сохранении.** Сохранение ru-текста сразу отправляет его в DeepL.
  Если DeepL не ответил, у записи остаётся статус `failed`, и в админке её можно
  перевести заново кнопкой.


## Структура

| Папка | Что это | Порт |
|---|---|---|
| `frontend/` | Next.js: сайт + API + доступ к БД | 3000 |
| `admin/` | Vite + React SPA, FSD-архитектура | 3001 |
| `db` (docker) | PostgreSQL | 5432 |
| `dozzle` (docker) | просмотр логов контейнеров | 8888 |
| `backend/` | NestJS, заморожен, будет удалён из main | — |

## Стек

- **Next.js 16** (App Router, RSC, Cache Components, server actions), React 19.2, TypeScript. Сейчас стоит 15.5, обновление запланировано
- **next-intl**: локали `ru` / `en`
- **ORM**: Prisma или Drizzle (не выбрано)
- **Zod**: одна схема валидации и для API, и для форм админки
- **SCSS modules**
- **Vite + React Router + TanStack Query**: админка
- **DeepL API**: перевод ru → en

## Запуск

```bash
docker compose up
```

Env-файлы: `./.env` (Postgres), `./frontend/.env`, `./admin/.env`.

- сайт: http://localhost:3000
- админка: http://localhost:3001
- логи: http://localhost:8888

## Разделы

**Сайт:** главная, обо мне, услуги, отзывы, FAQ, статьи, контакты.

**Админка:**

| Раздел | Что умеет |
|---|---|
| FAQ | список вопросов, порядок перетаскиванием, статус перевода |
| Отзывы | добавление, правка, публикация |
| Статьи | добавление и редактирование статей, видео |
| Услуги и цены | правка без участия разработчика |
| Заявки | сообщения с формы связи и записи на консультацию |
| Статистика | популярность статей и услуг |

**Telegram-бот (Go, позже).** Это отдельная песочница: уведомления о заявках,
напоминания о консультациях, модерация отзывов кнопкой, недельный дайджест.
Если бот упадёт, на сайт это не повлияет.

## Направление по дизайну

Мягкая детская тема: микро-интеракции на hover и клик, лёгкая кинетическая
типографика, большие картинки с плавными переходами, обыгрываем гранат.
Без агрессивного параллакса и 3D. Анимации в приоритете на CSS
(scroll-driven animations), Motion там, где нужен стейт.
